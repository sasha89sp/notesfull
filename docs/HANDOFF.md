## Что это
**ASRbox** (пакет `mysecure_notes`) — кроссплатформенное приложение Flutter: зашифрованные заметки (блоки, таблицы, Markdown, вложения, голос), календарь и задачи, пароли, общие папки (группы с правами и чатом), бэкапы. Платформы: Android, Windows (основные), Linux/macOS (экспериментально). Синхронизация: WebDAV, Google Диск, локальная папка. Репозиторий GitHub `sasha89sp/notesfull`.

## Как работает владелец проекта
- Пишет по-русски. Работа **только через чат**; локального компилятора Flutter нет.
- Сборка и тесты — GitHub Actions (`.github/workflows/build.yml`: test, android, windows, linux*, macos*; * экспериментальные). Результат владелец присылает скриншотом/текстом ошибки.
- Код, который я пишу, **не компилируется у меня**: в конце каждого ответа об этом говорить. Проверка — только CI.
- **Правило владельца:** прежде чем добавлять/менять плагин (пакет pub), сначала коротко написать, что будет сделано, и дождаться разрешения.
- Любит получать всё сразу; но задачи лучше резать небольшими.

## Известные ограничения и хвосты
- В компьютерном виде у календаря, общей папки и бэкапа нет собственной шапки с названием (AppBar оболочки убран) — при желании добавить заголовок.
- Контекстное меню по правой кнопке сделано для компьютерных списков заметок/паролей; в мобильных списках — прежние меню.
- PDF не включает картинки/вложения. Формулы таблиц в PDF — как текст.
- Фоновая синхронизация требует биометрию (ключи в защищённом хранилище) и разрешений автозапуска на китайских прошивках (Motorola).
- Права в группах «мягкие» (проверяет клиент); шифрование приглашений — обфускация.
- SMS восстанавливаются только если приложение — SMS по умолчанию; пароли Wi-Fi на Android 10+ недоступны.
- Расписание автобэкапа телефона работает пока приложение живо (и в фоне при включённом WorkManager).
- Большие файлы (кандидаты на дробление): см. конец `docs/CODEMAP.md`.

## Как продолжить в новом чате
1. Приложить **последний архив** проекта (`mysecure_notes_full.zip`) и вставить стартовое сообщение:

> Это проект Flutter-приложения ASRbox, архив приложен. Прочитай `docs/HANDOFF.md`, затем `docs/ARCHITECTURE.md` и `docs/CODEMAP.md`; остальные файлы открывай только по необходимости. Я работаю только через чат, локального компилятора нет, сборка на GitHub. Меняй только то, что относится к задаче, ничего не рефакторь без просьбы. Отвечай изменёнными файлами целиком в формате `=== FILE: путь ===` … `=== END ===` и новым архивом. В конце обнови `docs/HANDOFF.md` и `docs/DECISIONS.md`. Задача: …

2. Если ИИ не умеет работать с архивом: `python3 tools/brief.py <файлы>` создаёт `brief.txt` (документы + нужные файлы), его вставляют текстом.
3. Ответ ИИ в формате блоков применяется командой `python3 tools/apply.py ответ.txt` (делает резервные копии в `.apply_backup/`, проверяет скобки, обновляет карту).
4. Ошибки CI вставлять в тот же чат текстом (последние 30–50 строк упавшего шага).
