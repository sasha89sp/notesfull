# ASRbox

Flutter-приложение для Android и Windows: заметки с блоками, таблицы, календарь, менеджер паролей. Всё шифруется AES-256-GCM, синхронизация через WebDAV (Mail.ru Облако).

## Как получить приложение

1. Создайте репозиторий на GitHub и залейте в него содержимое этой папки (включая скрытую `.github`).
2. Вкладка **Actions** → сборка запустится сама (или **Run workflow**).
3. Через 8–15 минут в запуске внизу, в разделе **Artifacts**:
   - `android-apk-base` — обычный установочный `app-release.apk`
   - `windows-app-base` — папка с `ASRbox.exe` (запускать из неё, соседние файлы нужны)
   - `android-apk-whisper` и `windows-app-whisper` — то же, но с локальной расшифровкой голоса (Whisper)
   - `android-apk-autofill` — Android-сборка с сервисом автозаполнения паролей в других приложениях (Android 8+)
   - `linux-app` и `macos-app` — экспериментальные сборки, не проверялись
   Дополнительные варианты собираются отдельно: если один из них упадёт, обычные сборки от этого не пострадают

Папки `android/` и `windows/` создаёт CI командой `flutter create`, а скрипт `ci/patch_android.py` добавляет разрешения, ресиверы уведомлений и запрет скриншотов. Хранить их в репозитории не нужно.

Если сборка упала, откройте упавший шаг в Actions, скопируйте текст ошибки и пришлите разработчику.

## Что есть

**Безопасность**
- Мастер-пароль (от 8 символов), AES-256-GCM, ключ из пароля через PBKDF2 (100 000 итераций)
- Вход по биометрии (Android; Windows Hello): ключ лежит в Keystore / DPAPI
- Менеджер паролей с отдельным мастер-паролем и отдельным ключом, автоблокировка, запрет скриншотов на Android (FLAG_SECURE), буфер обмена очищается через 30 с

**Заметки**
- Блоки: текст (Markdown), таблица, голосовая запись + транскрипт, фото, файл, чек-лист, цитата, код; перетаскивание
- «Только я» / «Семья», теги, избранное, поиск, группировка по датам, история версий (до 8) с откатом
- Авторство: кто создал и кто изменил
- Комментарии к семейным заметкам: отдельные зашифрованные файлы, автор удаляет в течение 5 минут, автор заметки — всегда, остаётся пометка «[Комментарий удалён]»

**Таблицы**: сетка с виртуализацией строк, формулы (+ − * / скобки, SUM, AVERAGE, MIN, MAX, COUNT, диапазоны), цвет фона и текста, объединение ячеек, режим просмотра / правки, импорт и экспорт .xlsx

**Календарь**: месяц / неделя / день / список, события и задачи с чекбоксом, напоминания, импорт и экспорт .ics, двусторонняя синхронизация с Google Календарём по HTTPS (без Google Play Services)

**Пароли**: папки, избранное, генератор, TOTP, история паролей. Импорт: Bitwarden (JSON, CSV), KeePass (XML), LastPass (CSV), 1Password (.1pif, CSV), Chrome / Firefox / Safari (CSV), общий CSV. Экспорт: CSV, Bitwarden (JSON, CSV), KeePass XML

**Уведомления**
- Android: AlarmManager через flutter_local_notifications, работает без GMS, после перезагрузки восстанавливаются; мастер настройки батареи и автозапуска (Xiaomi, Huawei, Honor, Motorola)
- Windows: закрытие крестиком сворачивает в трей; напоминание — отдельное маленькое окно в правом нижнем углу поверх всех окон, со звуком, висит до закрытия, кнопки «Открыть» / «Закрыть»

**Синхронизация WebDAV**: атомарная загрузка (`.tmp` → `MOVE`), манифест, скачиваются только изменённые файлы. Триггеры: изменение данных, открытие / возврат в приложение, появление сети, таймер 30 минут. Вложения: по умолчанию только Wi-Fi. Если заметку правили на двух устройствах, правки сливаются автоматически: по блокам, по строкам текста, по ячейкам таблицы, по пунктам чек-листа. Только когда обе стороны изменили одну и ту же строку, ячейку или блок, серверная версия сохраняется копией «(конфликт)».

## Вход, профили и данные

- Экран входа: логин (имя профиля), пароль, «Запомнить», вход по биометрии. Если профиль на устройстве уже есть, вход идёт сразу в него; новый создаётся отдельной кнопкой («локальный», «онлайн», «войти в существующий» по веб-адресу WebDAV).
- Несколько профилей на устройстве: «Выйти из профиля» и «Сменить профиль» в Настройках. Данные каждого профиля лежат в своей папке.
- Настройки сохраняются автоматически; при вводе данных WebDAV синхронизация запускается сама.
- Боковое меню: внизу кнопка «Синхронизировать», прогресс с кнопкой «Отменить» и итог последней синхронизации.
- Настройки → «История синхронизации»: дата, статус, сколько заметок, паролей, событий, папок отправлено и получено, куда, подробный журнал, экспорт файлом.
- Настройки → «Отладка»: журнал ошибок, сбоев и зависаний интерфейса, подробный режим, экспорт файлом.
- Подключения: «Выйти из WebDAV», «Отмена», «Выйти из Google Календаря».
- Папки заметок с вложенностью (создать, переименовать, переместить, удалить), папки паролей (создать, переименовать, удалить); синхронизируются.
- Вкладка «Пароли»: «Сохранить пароль» на 15 минут, 30 минут, час, день или до выхода из профиля; сброс вручную в меню ⋮.
- Полный бэкап и восстановление (zip), импорт и экспорт Joplin (JEX), календаря (ICS), паролей (CSV и др.).
- Синхронизация календаря не должна зависать: тяжёлое шифрование и разбор идут в отдельном потоке, события ищутся по индексу, одинаковые события не дублируются, уведомления перепланируются не чаще раза в 2 секунды и только при изменениях.

## Тесты

В папке `tests/` лежат юнит-тесты (шифрование, TOTP по RFC 6238, формулы, CSV, .ics, .xlsx, слияние заметок). В Actions они идут отдельной задачей `test` и не блокируют сборку APK.

## Настройка

**Mail.ru Облако**: Настройки → адрес `https://webdav.cloud.mail.ru`, логин — почта, пароль — «пароль для внешнего приложения» с доступом WebDAV (Mail.ru → Безопасность).

**Несколько устройств одного человека**: на втором устройстве создайте хранилище с тем же мастер-паролем и теми же данными WebDAV — личные заметки, события и пароли синхронизируются (ключ синхронизации выводится из пароля).

**Семья**: владелец нажимает «Создать семейный ключ» (Настройки → Семья). У каждого участника при синхронизации создаётся пара ключей X25519; владелец в списке «Участники» нажимает «Дать доступ», и на сервере появляется обёртка семейного ключа для этого участника. Остальные получают ключ автоматически при следующей синхронизации. Папку `MySecureApp/FamilyShared` и `keys` владелец расшаривает в Mail.ru Облаке. Старый способ с общим «Семейным паролем» оставлен, но с ключами не сочетается.

**Автозаполнение (сборка autofill)**: Настройки → «Включить автозаполнение», выбрать «Заметки». При входе в другое приложение или сайт в браузере предложат список паролей; открывается окно с вводом пароля от хранилища. Записи сортируются по совпадению с адресом или названием приложения.

**Google Календарь**: в Google Cloud Console создайте проект, включите Calendar API, создайте OAuth-клиент «Desktop app», вставьте Client ID и Secret в Настройках и нажмите «Войти в Google». Вход через браузер на том же устройстве; удобнее выполнять на Windows.

**Транскрипция голоса**
- Сборка `whisper`: локальная расшифровка без интернета (whisper.cpp). Модель (Tiny ≈75 МБ, Base ≈140 МБ, Small ≈460 МБ) скачивается один раз при первой расшифровке. Для русского лучше Base или Small. Запись идёт в WAV 16 кГц моно (≈2 МБ в минуту).
- Любая сборка: облачный Whisper-совместимый API (Настройки → Голос → адрес, ключ, модель).

## Отличия от ТЗ

- Папки заметок общие для личных и семейных заметок и синхронизируются в личной области. Joplin: импорт и экспорт заметок, папок, тегов и вложений; свойства Joplin вне этого набора не переносятся.
- Хранилище: зашифрованные файлы вместо SQLite + SQLCipher (то же шифрование AES-256, проще сборка).
- Семейный ключ: обёртки X25519 реализованы; ключ выдаёт владелец вручную.
- Локальный Whisper есть только в отдельной сборке `whisper`; в обычной доступен облачный API.
- KeePass: импорт из XML (экспорт .kdbx из KeePass в XML). Сам .kdbx зашифрован, напрямую не читается.
- Автозаполнение есть только на Android и только в сборке `autofill`; расширений для браузеров на Windows нет.
- iOS не собирается (нужна подпись Apple). Linux и macOS: экспериментальные задачи CI, не проверены.
- Слияние строк работает, если число строк в блоке не менялось с обеих сторон; иначе версия с сервера сохраняется копией.
- Уведомления Windows: отдельное окно реализовано как временное сжатие главного окна, а не как второй процесс.
- Объединение ячеек по вертикали отображается упрощённо (значение в верхней ячейке).


## ASRbox: что нового

**Двухуровневый вход.** «Подключить хранилище»: 1) WebDAV (логин и пароль облака) или обычная папка на устройстве → 2) выбор существующей папки с данными или создание новой → 3) свой логин и пароль ASRbox. Если аккаунта в папке нет, он создаётся (пароль повторяется дважды, восстановить его нельзя).

**Изоляция пользователей.** На одном WebDAV может быть сколько угодно аккаунтов. У каждого своя папка `users/<id>` и свой ключ AES-256-GCM, выведенный из его пароля, поэтому чужие данные не прочитать, даже имея доступ к WebDAV. Реестр `accounts/` хранит только зашифрованную проверочную метку, пароли в облако не попадают.

**Внутренние настройки едут с аккаунтом.** Подключение к Google Календарю, ключи семьи, модули, внешний вид и прочее хранятся в зашифрованном `settings.enc`. При входе в старую папку со своим логином всё подтягивается само (побеждает версия с более поздней отметкой времени). Данные доступа к самому хранилищу в облако не отправляются.

**Модули:** Заметки, Календарь, Пароли, Чаты. Настройки → «Модули»: отключённый модуль не показывается и не загружается. Связи работают независимо от этого: «Добавить в календарь» в заметке создаёт событие (с напоминанием) даже при отключённом календаре; сообщение чата можно превратить в заметку или событие.

**Общая группа через разные WebDAV.** Настройки → «Общая группа»: отдельный WebDAV для общих заметок, комментариев и чата. Участники могут входить каждый через свой личный WebDAV, но делить группу. Приглашение копируется и вставляется одной кнопкой; семейный ключ выдаёт владелец в «Участники».

**Чат.** Каждое сообщение — отдельный файл, зашифрованный семейным ключом; только добавление, поэтому конфликтов нет. Обновляется каждые 20 секунд на открытом экране и при обычной синхронизации.

**Надёжность файлов.** Запись идёт через временный файл, предыдущая версия остаётся как `.bak`; при повреждении данные читаются из резервной копии. Запросы к WebDAV повторяются при сбоях сети, загрузка в облако атомарная.

**Старые данные.** Профили прежней версии работают как раньше. Папку `MySecureApp` без аккаунтов можно подключить переключателем «Данные старой версии».

## Доработка: бэкап на WebDAV, Markdown как в Joplin, импорт

**Бэкап на WebDAV.** Настройки → «Резервная копия и перенос». Сервер для бэкапов: текущий WebDAV (папка `backups/<аккаунт>`) или отдельный WebDAV. Галочка «После создания бэкапа загружать на сервер»: нажали «Полный бэкап», файл сохранился на устройство и сам ушёл на сервер, без вопросов. Дополнительно «Делать бэкап сам раз в сутки», лимит хранимых копий (старые удаляются), кнопки «Бэкап на сервер сейчас» и «Бэкапы на сервере» (список и восстановление). Бэкап остаётся зашифрованным вашим паролем.

**Редактор.** Текстовый блок теперь Markdown с панелью как в Joplin: отмена/повтор, заголовки 1–6, жирный, курсив, зачёркнутый, подчёркнутый, выделение, код, ссылка, маркированный, нумерованный и чек-список, цитата, линия, таблица, дата и время, изображение, файл. Enter продолжает список, Ctrl+B/I/K на компьютере. В покое текст отрисован (таблицы, код, картинки, вложения, ссылки на заметки `:/id`), галочки нажимаются прямо в просмотре. Нажатие по тексту возвращает к правке.

**Импорт из Joplin.** Кнопка теперь выбирает любой файл (Android не распознаёт .jex по расширению) и показывает ход импорта. Заметка переносится целиком как Markdown: форматирование, таблицы, код, чек-листы, вложения (под прежними id, ссылки не ломаются), теги, папки, даты создания. Дополнительно: HTML-заметки конвертируются в Markdown, задачи Joplin становятся задачами календаря (срок, статус), адрес источника и координаты дописываются в конец, корзина пропускается. Повторный импорт дублей не создаёт. Не поддерживается: формулы и диаграммы (показываются как текст), история ревизий Joplin.

**Лаги после синхронизации календаря.** Сообщения о ходе больше не перерисовывают интерфейс чаще 5 раз в секунду, календарь строит индекс событий по дням один раз за перерисовку, а не на каждую ячейку.
